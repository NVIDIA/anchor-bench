What is Anchor Bench?

Anchor Bench validates YAML task configurations and runs reproducible robot actuator workflows. It generates command trajectories, identifies actuator parameters with Newton, trains recurrent models, and records structured artifacts for every run.

Configuration-driven tasks

Strict YAML schemas make trajectory, identification, and training runs explicit and repeatable.

Reproducible artifacts

Validated configurations, task outputs, and completion markers keep every run inspectable.

Data and tracking

Parquet dataset tooling and MLflow integration connect inputs, metrics, and generated artifacts.
