What is Anchor Bench?

Anchor Bench is a focused system identification (SysID) and sim-to-real benchmark package for robot actuator models on the Isaac Sim, Newton, and Isaac Lab versions pinned in versions/compatibility.toml. It provides robot configs, data loaders, SysID and Newton benchmark command builders, and analysis helpers around the actuator-identification workflow.

Declarative robots

Add and configure robot support entirely under configs/robots/ — no code changes required.

Docker-first workflow

A pinned Isaac Lab image keeps every SysID and benchmark run reproducible across machines.

Analysis pipelines

SysID, benchmark, and analysis stages emit SAGE-compatible outputs ready for comparison.
