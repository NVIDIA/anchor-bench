# Archived command-line guide

This page described a container and subcommand interface from an earlier
architecture. Commands such as `robots`, `sysid`, `train-actuator`, `benchmark`,
and `analyze` are not part of the current command-line interface.

The supported interface runs one YAML task with `anchor-bench --config`; see
[Command-line usage](../README.md#command-line-usage) and
[Trajectory generation](trajectory.md). Historical contents remain available
through Git history.
